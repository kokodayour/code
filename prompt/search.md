# 任务目标
查找关于指定主题“xxx”的最新英文文献，并按照给定要求整理成规范的参考文献列表。

# 输入条件
- 主题关键词：“xxx”
- 文献类型：仅限发表在SCI或SSCI索引期刊的英文文献
- 时间范围：优先选择近五年内发表的研究成果
- 数量要求：至少提供5篇相关文献
- 格式要求：每篇文献需包含标题、作者、发表年份、期刊名称、摘要
- 排序与引用格式：最终结果按APA格式（第7版）排列成参考文献列表

# 执行步骤
1. 使用主题词“xxx”在权威学术数据库（如Web of Science、PubMed、Scopus或Google Scholar）中进行检索。
2. 筛选出同时满足以下条件的文献：
   - 收录于SCI或SSCI索引期刊；
   - 发表年份为2021年及以后（若近五年内文献不足5篇，可适当放宽至近十年，但需优先列出近五年的文献）；
   - 语言为英文。
3. 从筛选结果中，优先选择影响因子较高或领域内公认的核心期刊文献，以确保学术价值。
4. 对每篇入选文献，提取并记录：标题、所有作者姓名、发表年份、期刊全称、摘要内容。
5. 将选定的文献按APA格式（第7版）生成参考文献列表，并按第一作者姓氏字母顺序排列。

# 输出格式
- 输出内容分为两部分：
  1. **文献摘要列表**：每篇文献以编号（1. 2. 3. ...）开头，依次列出标题、作者、年份、期刊、摘要，各项信息清晰分行。
  2. **参考文献列表**：将上述文献按APA第7版格式排列，并置于“## References”标题下。
- 整体输出使用Markdown格式，确保结构清晰、可读性强。

# 质量约束
- 所有文献信息必须真实可查，不得编造或虚构数据。
- 每篇摘要需为原文摘要的准确概括或直接引用（若直接引用，请加引号并标注来源）。
- 若检索结果不足5篇，需明确说明，并补充检索策略调整建议（如扩大时间范围或同义词扩展），但不得编造文献。

# 边界说明
- 本任务仅负责检索、筛选和格式化整理，不提供对文献内容的深度分析或评价。
- 若用户未提供“xxx”的具体内容，请提示用户补充主题词，否则无法执行检索。
