# 快慢指针

#### 背景: 使用两个速度不一(通常快指针速度是慢指针的两倍)的指针遍历数据 利用速度差揭示位置关系

- 判断链表是否有环
- 寻找环的入口点
- 寻找链表中点
- 寻找倒数第N个点(快指针比慢指针先走N)

#### 具体步骤:

1. 初始化快慢指针
2. 快指针一次移动两个节点 慢指针一次移动一个节点
3. 是否满足退出条件


#### 反思:

`fast and fast.next`的顺序不能错  
`is`的速度要快于`==`  
如果头节点会发生变化(即第一个位置不是一成不变的)就需要使用dummy时刻指向新的头节点从而保留头结点的位置  
注意看题目给出的ListNode的定义 比如是否给出了val的默认值

#### 模板:

```python
slow = fast = head
while fast and fast.next:
    fast = fast.next.next
    slow = slow.next
    # 退出条件
    if fast is slow:
```
