-------------------------------------------------
公众智能体：
输入 LUCCMap
    ↓
读取适宜性 → 遍历所有用地类型
    ↓
逐类计算：邻域环境 + 四项因子加权得分
    ↓
单类得分 / 总得分 → 得到选择概率
    ↓
维度转换 → 逐像元概率判定（蒙特卡洛）
    ↓
输出：公众决策图 + 适宜性数组
-------------------------------------------------
部门智能体：
输入 LUCCMap
    ↓
调用公众智能体 → 得到公众决策图 + 公众适宜性
    ↓
加载开发适宜性、基于公众结果构建学习图层
    ↓
生成全域禁开发掩膜、批量生成用地二值图、计算斑块集聚度
    ↓
遍历每一类模拟用地
    ├─ 计算本轮最大扩张数量（规模约束）
    ├─ 加权计算开发综合分值
    ├─ 无效区域分值清零
    └─ 按分值+限额+禁建区，生成单类用地备选图
    ↓
汇总所有用地的备选方案
    ↓
输出：多套备选方案 + 两类适宜性数据
